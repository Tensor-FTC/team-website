# Images

Drop site images here. Referenced from code as absolute paths, e.g. `/images/robot-hero.jpg`.

Used by the placeholder content out of the box:

- `robot-hero.jpg` — home page hero (portrait works best)
- `robot-full.jpg` — full robot view on the Robot page
- `team-photo.jpg` — group photo on the About page
- `team/` — member portraits, referenced from `src/data/teamMembers.ts`
- `projects/` — project images, referenced from `src/data/projects.ts`
- `outreach/` — event photos, referenced from `src/data/outreachEvents.ts`
- `sponsors/` — sponsor logos, referenced from `src/data/sponsors.ts`

Anything missing renders as a frosted gradient placeholder instead of a broken
image, so you can add these one at a time.
